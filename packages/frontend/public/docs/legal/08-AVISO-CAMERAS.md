# AVISO DE MONITORAMENTO POR CÂMERAS

**Documento para afixação física no estabelecimento**
**Versão:** 1.0

---

## 🚨 IMPORTANTE

A LGPD não exige consentimento para monitoramento ambiental por câmeras com fim legítimo (segurança), **MAS exige TRANSPARÊNCIA**. Sem aviso visível, o tratamento é considerado **obscuro** e gera passivo legal.

A empresa-Cliente deve afixar este aviso em **todos os pontos relevantes** do estabelecimento.

## NORMAS APLICÁVEIS PARA O CLIENTE

O Cliente que opera o estabelecimento deve:

1. **Instalar avisos visíveis** antes de ativar gravação;
2. **Comunicar formalmente os colaboradores** sobre o monitoramento (no contrato CLT ou regulamento interno);
3. **NÃO instalar câmeras em áreas de privacidade** (banheiros, vestiários, salas de amamentação);
4. **Restringir acesso às imagens** a pessoal autorizado, com log de acesso;
5. **Definir prazo de retenção razoável** (sugestão: 30-90 dias);
6. **Ter procedimento documentado** para acesso a imagens em caso de incidente;
7. **Não usar imagens para vigilância indevida** de funcionários (ex: monitoramento de pausas);
8. **Em caso de gravação de áudio**, há restrições adicionais — recomendamos NÃO gravar áudio;
9. **Atender solicitações de titulares** (ex: cliente que pede sua própria imagem para denunciar furto contra ele).

## CHECKLIST DE CONFORMIDADE

- [ ] Avisos legíveis a 1,5 metro de distância;
- [ ] Áreas privadas (banheiro/vestiário) sem câmera;
- [ ] Câmeras configuradas para não captar áudio (ou termo separado se gravar);

- [ ] Política de Privacidade publicada com seção sobre câmeras;
- [ ] Procedimento de acesso/exportação de imagens documentado;
- [ ] Logs de acesso a gravações registrados;
- [ ] Backup das gravações controlado e excluído após retenção;
- [ ] Funcionários cientes via contrato/regulamento interno.
